# 26-27 学年 课后延时安排查询

小学课后延时（社团 / 俱乐部）报名查询页面。

## 功能
- 班主任视角：按年级 + 班级查看本班学生报了哪些社团 / 俱乐部，谁没报
- 授课教师视角：按社团 / 俱乐部名称查看名单，跨班汇总
- 分「周一周二」「周三周四」两个时段
- 支持登录后增删改（账号由管理员分配），未登录只读

## 访问
GitHub Pages：https://misakaluohua-svg.github.io/club/

## 数据
数据存储于腾讯云 CloudBase PostgreSQL（表 `student_club`），
页面通过云函数 API 网关读写，匿名只读、登录后可改。
